# Bivaque React — 21st.dev nativo

Branch experimental, independente da R72 original e da produção.

- 18 componentes originais preservados em `src/components/21st/upstream/`.
- 5 adaptações pontuais (navegação controlada, correção de tipagem, BRL, CTA e preferências) em `src/components/21st/`.
- React 18, TypeScript, Vite, Tailwind. Build `npm install && npm run build` executa auditoria de origem.
- Fotos do projeto público Bivaque, dados da demonstração, sem backend, autenticação ou persistência real.
- A versão em produção não é alterada.

Fonte de rastreabilidade: `source-manifest.json`. O relatório de build na Vercel comprova a instalação e compilação; testes E2E funcionais precisam de execução separada.
