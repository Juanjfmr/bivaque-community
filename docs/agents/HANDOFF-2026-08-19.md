## Gotchas de ambiente (para não repetir)

- `pnpm` não está no PATH — usar `npx pnpm@11.18.0`.
- Navegador gerenciado do Playwright não está instalado — setar
  `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH = "C:\Program Files\Google\Chrome\Application\chrome.exe"`.
- **`--slowmo` NÃO é flag válida do `playwright test`** (só existe em `browser.launch`).
  Usar `--headed`; câmera lenta exigiria config.
- `next start` zumbi: o `loop.mjs` mata só o wrapper `npx pnpm`, não o child
  `node next start`. Se o `next build` reclamar "Another next build process is already
  running", mate os `node` com `next start`/`next build` na linha de comando.
